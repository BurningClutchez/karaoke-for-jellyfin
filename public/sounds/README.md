# Applause sounds

The TV plays one of these at random on the rating screen after each song (`src/components/tv/ApplausePlayer.tsx`):

- `applause-1.mp3`, `applause-2.mp3`, `applause-3.mp3`
- `applause-crowd.mp3`, `applause-crowd-2.mp3`

To use your own, replace them with files of the same names: MP3, 3–5 seconds, normalized volume. If a file is missing or the browser refuses to play it, the rating screen is simply silent.
